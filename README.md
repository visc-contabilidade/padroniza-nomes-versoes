# Padroniza Nomes — versões

Este repositório contém **somente as versões publicadas** da ferramenta Padroniza Nomes,
usada pelos operadores do fiscal para renomear e organizar os PDFs exportados do Domínio.
O código-fonte não fica aqui.

Nenhum dado de cliente está neste repositório nem no pacote. Os dados vêm do sistema
interno do escritório e só ficam acessíveis depois do login com o email institucional.

## Baixar a versão mais recente

[padroniza-nomes.zip](https://github.com/visc-contabilidade/padroniza-nomes-versoes/releases/latest/download/padroniza-nomes.zip)
— o link sempre aponta para a última versão.

## Instalar ou atualizar

1. Baixe o `padroniza-nomes.zip` pelo link acima.
2. Clique com o botão direito no zip, **Propriedades**, marque **Desbloquear** e clique em OK.
3. Extraia para `Documentos\PadronizaNomes` (numa atualização, extraia por cima).
4. Na primeira vez, dê duplo clique em `PadronizaNomes.cmd` e responda **S** quando a ferramenta
   oferecer criar o atalho **Padroniza Nomes**, com ícone, na área de trabalho.
5. Use sempre o atalho. O `LEIA-ME.txt` que vem no pacote explica o resto.
